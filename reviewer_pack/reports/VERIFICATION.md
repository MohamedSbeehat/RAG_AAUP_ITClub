## سبب التعذر

أعيد فحص المزود بطلب تشخيصي منفصل، فأعاد **HTTP 429**، بالحد:

```text
quotaId: GenerateRequestsPerDayPerProjectPerModel-FreeTier
quotaValue: 20
suggested retry delay at the time of the probe: 70568s
```

من أخطاء API الـ28، أظهرت 26 رسالة سبب الحصة صراحةً، وكانت رسالتا الإنجليزية عامتين عن تعذر التوليد. لم نستبدل المزود بنموذج محاكى أو نعتبر الاسترجاع إجابة ناجحة. أُوقفت طلبات Gemini الإضافية بعد تأكيد الحد اليومي.

## ماذا جرى إصلاحه؟

- متابعة «واذا» دون همزة و«وشو» و«وكم» تحتفظ بأسئلة المستخدم السابقة، بما فيها السؤال الأصلي عبر أكثر من رسالة؛ لا تعيد استخدام ادعاءات إجابة قديمة كدليل.
- توضيح تعليمات فهم اللهجة الفلسطينية والإجابة بالعربية البسيطة، وطلب المعلومات الناقصة، والاستشهاد بكل سياسة لازمة للحساب، ورفض الطلبات خارج نطاق الملفات.
- تصحيح قراءة أسماء مراجع Windows في سكربت تقييم الخطط. لم تتغير البصمات أو الإجابات المتوقعة لجعل التقييم ينجح.
- إضافة مجموعة `smoke` من 16 حالة وخيار `--case-ids` مع تضمين سياق المتابعة تلقائياً، لتسهيل إعادة التجربة ضمن حصة صغيرة. مجموعة smoke نفسها لم تُشغّل على Gemini بعد نفاد الحصة؛ توجد اختبارات لاختيارها وسياقها.

## إعادة التحقق

اتبع [دليل المقيّمين](../README.md). للمجموعة القصيرة استخدم:

```powershell
uv run python scripts/evaluate_reviewer_pack.py --mode live --profile smoke --output outputs/reviewer-smoke
```

وللجولة الكاملة استخدم `--profile full` مع حصة تسمح بـ42 طلباً على الأقل. لا ترفع تقارير النتائج أو `cases.json` إلى قاعدة المعرفة.

فحص الأنماط ليس تحكيماً دلالياً مستقلاً. راجع النتيجة النهائية ومصادر كل ادعاء، خاصةً جمع السياسات والامتناع. لا تشمل هذه الجولة اختبار أحمال إنتاجي أو خادم Qdrant خارجي أو تدقيقاً أمنياً مستقلاً أو متصفحاً فعلياً أو OCR لصور جديدة. أُعدت صفحات PDF التجريبية ورُوجعت صورها بصرياً.
