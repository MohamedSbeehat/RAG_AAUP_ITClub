# CampusIQ - مساعد مستندات عربي/إنجليزي للشركات والجامعات

ارفع ملفات المؤسسة، ثم اسأل بالعربية أو الإنجليزية لتحصل على إجابة مع رابط إلى **المستند المحلي وصفحته**. عند غياب الدليل يمتنع المساعد. لكل شركة حساب وملفات وفهرس ومحادثات مستقلة.

## للمقيّمين: ابدأ من هنا

حزمة تجربة صغيرة موجودة داخل المستودع في **[reviewer_pack](./reviewer_pack/README.md)**. فيها خمسة مستندات وهمية عامة و42 سؤالاً، مع المتوقع وتقارير التشغيل. لا تحتاج تنزيل لوائح الجامعة لتجربتها.

الملفات الحالية على فرع `setup/project-structure`. لتنزيل هذه النسخة مباشرةً:

```powershell
git clone --branch setup/project-structure https://github.com/MohamedSbeehat/RAG_AAUP_ITClub.git CampusIQ
cd CampusIQ
```

1. شغّل `start-company.cmd` على Windows، أو `sh start-company.sh` على Linux. يلزم [uv](https://docs.astral.sh/uv/getting-started/installation/)؛ أول تشغيل ينزّل Python والاعتماديات ونموذج التضمين، ويحتاج إنترنت ومساحة على القرص.
2. ينسخ المشغّل `.env.company.example` إلى `.env` إذا لم يوجد. أضف مفتاحك إلى `GEMINI_API_KEY` واختر نموذجاً متاحاً لحسابك. **لا ترفع `.env` إلى GitHub**. يمكنك استخدام Ollama بدلاً منه عند تشغيله وضبط النموذج.
3. افتح <http://127.0.0.1:8000> وأنشئ حساب شركة جديداً بنوع «مراجع أكاديمية» لتجربة حزمة الجامعة الوهمية.
4. من Documents ارفع **الملفات الخمسة داخل [reviewer_pack/documents](./reviewer_pack/documents/)** فقط، وانتظر انتهاء الفهرسة. لا ترفع دليل الاختبار أو الأسئلة أو النتائج إلى RAG، ولا تضف مراجع AAUP إلى هذا الحساب أثناء الاختبار.
5. من Chat اختر «كل ملفات شركتي» و«إجابة بالمساعد». جرّب الأسئلة أدناه وافتح المصدر. بدون مزود توليد اختر «المقتطفات فقط»؛ هذه تجربة استرجاع وليست اختبار إجابات أو امتناع.

| الاختبار | السؤال | المتوقع من بيانات التجربة الوهمية |
| --- | --- | --- |
| مباشر | ما الحد الأدنى لنسبة الحضور في المادة؟ | 75% مع PDF الصفحة 1. |
| فلسطيني | شو بصير إذا غبت أكتر من المسموح وما معي عذر مقبول؟ | تجاوز 25%: حرمان من النهائي وصفر، مع مصدر. |
| جدول | كم ساعة معتمدة لمادة البرمجة المتقدمة CS102؟ | 4 ساعات من الصف الصحيح. |
| أكثر من ملف | معدلي 2.1 وأنا سنة ثالثة، كم ساعة بقدر أسجل؟ | الأقل بين حد المعدل 15 وسقف السنة 18 =15، مع المستندين. |
| متابعة في نفس المحادثة | واذا صار معدلي ٣٫٧؟ | يتذكر السنة الثالثة: الأقل بين 21 و18 =18. |
| معلومة ناقصة | متى موعد امتحان الخوارزميات؟ | يقول إن الموعد غير موجود ويحيل لشعبة الامتحانات، دون اختراع تاريخ. |
| خارج النطاق | اكتبلي قصيدة عن الجامعة | يوضح حدود مساعد المستندات ولا يكتب قصيدة. |

ابدأ «محادثة جديدة» لكل سؤال مستقل؛ أسئلة المتابعة تبقى في المحادثة نفسها. الدليل يشرح سلاسل الضمائر عبر عدة رسائل، «قديش/هسا/إلها»، والأرقام العربية وحدود المعدل والغياب. هذه الأرقام **ليست لوائح AAUP**.

## تشغيل الاختبارات

```powershell
uv sync --locked --group dev
uv run pytest -q
uv run ruff check src tests scripts
uv run ruff format --check src tests scripts
uv lock --check
node tests/workspace_ui.test.mjs
uv run python scripts/evaluate_reviewer_pack.py --mode retrieval --output outputs/reviewer-retrieval
uv run python scripts/evaluate_reviewer_pack.py --mode live --profile smoke --output outputs/reviewer-smoke
```

- `pytest`: تحميل الملفات والتقسيم والفهرسة المتزايدة وQdrant والإصدارات والاستشهاد والامتناع، وAPI وعزل الشركات والجلسات والحذف والتعافي من أخطاء التوليد. تستخدم بعض اختبارات الوحدة تضمينات أو مزودات محاكاة؛ ليست كلها استدعاءات LLM حقيقية.
- اختبار Node: الإرسال المكرر، عودة الزر بعد الخطأ والمهلة، ومسح بيانات العرض ورفض الاستجابات المتأخرة بعد تغيير الشركة. Node لا يلزم لتشغيل التطبيق.
- `retrieval`: يرفع مستندات الاختبار إلى مساحة مؤقتة ويستخدم e5 وQdrant فعليين دون LLM. يقيس أدلة 29 حالة؛ الامتناع وطلب التوضيح غير مقاسين بهذا الوضع.
- `live --profile smoke`: تجربة أقصر من 16 حالة تغطي الأنواع السبعة، باللغتين واللهجة الفلسطينية والمتابعة. `--profile full` يشغّل الحالات الـ42. يحتاج مفتاحاً وحصة متاحة وقد يستهلك رصيد المزود. لا تكفي حصة يومية من 20 طلباً لجولة كاملة من 42؛ استخدم المجموعة القصيرة عند توفر 16 طلباً على الأقل، أو اختر حالات عبر `--case-ids`. يحفظ السكربت الإجابات والمصادر والأزمنة والفحوص في JSON وMarkdown داخل `outputs/`، وينتهي برمز فشل عند الإخفاق.
- افتراضياً يعزل سكربت التقييم بياناته ويستخدم FastAPI TestClient. لا يحتاج إيقاف التطبيق. أضف `--base-url http://127.0.0.1:8000` لاختبار خادم HTTP فعلي؛ ينشئ حسابي اختبار جديدين، ولا يمس ملفات حساباتك.

**النتائج الفعلية وحدودها في [تقرير التحقق](./reviewer_pack/reports/VERIFICATION.md)**. فحص أنماط الكلمات والأرقام والمصادر لا يثبت دعم كل جملة دلالياً؛ راجع الإجابة مقابل المتوقع. لا تعتبر نتيجة الاسترجاع دقة LLM أو نتيجة الأسئلة المخفية للمسابقة.

## كيف تستخدمه شركة أخرى؟

اختر «إنشاء حساب شركة جديدة» ونوع «ملفات الشركة»، ثم ارفع PDF أو DOCX أو XLSX أو TXT أو Markdown أو PNG/JPG/JPEG. لا تُضاف ملفات AAUP تلقائياً. الواجهة تدعم السحب والإفلات وتقدم الرفع وحالة الفهرسة وتخطي المحتوى المتطابق، والتحديث والإزالة الفردية وإزالة الكل.

يظهر مجلد الشركة داخل Documents تحت «إضافة ملفات مباشرة إلى مجلد مساحة الشركة»: `workspaces/<tenant_id>/documents/`. يمكن نسخ ملفات إليه من جهاز الخادم؛ تُفهرس التغييرات تلقائياً كل 15 ثانية. لا تضع ملفات عدة شركات في مجلد مشترك.

تُستمد هوية الشركة من الجلسة الموثقة، ولا يختارها السؤال أو ترويسة مزورة. لكل شركة SQLite وQdrant وملفات مستقلة. الإزالة تنقل الملفات إلى `.rag_trash` الخاصة بها وتزيلها من الفهرس. الجلسات HttpOnly وSameSite، وكلمات المرور مملحة ومشتقة، وتوجد حدود للأسئلة والدخول وحماية Origin.

**حدود النشر:** مالك واحد لكل شركة حالياً، وعملية تطبيق واحدة عند Qdrant المحلي. استخدم HTTPS للنشر الخارجي. لا تشمل النسخة فوترة أو SSO أو أدوار موظفين متعددة أو شهادة تدقيق أمني أو اختبار أحمال إنتاجي. نسخة Gemini الحالية التي نجحت محلياً هي `gemini-3.5-flash`؛ التوافر والحصة يعتمدان على الحساب.

## مراجع AAUP الحقيقية - اختيارية ومنفصلة عن حزمة الاختبار

لإنشاء المراجع المحلية من صفحات الجامعة العامة:

```powershell
uv run rag-aaup sync-academic
```

ينتج الأمر PDF وصور صفحات، مع المصدر وتاريخ التحقق وبصمة المحتوى. يراعي robots.txt والنطاقات المعتمدة وفاصل الطلبات. من حساب أكاديمي اختر «إضافة مراجع AAUP المحلية» لنسخها إلى **مساحتك فقط**؛ ليس على حساب تجربة الجامعة الوهمية.

- ملف الشبكات: `output/pdf/AAUP_Computer_Networks_Reference.pdf`، 32 صفحة؛ علاقات المتطلبات السابقة في الصفحات 23-32.
- علم الحاسوب: `output/pdf/AAUP_Computer_Science_Reference.pdf`، 22 صفحة.
- الذكاء الاصطناعي والروبوت: `output/pdf/AAUP_AI_Robotics_Reference.pdf`، 23 صفحة.
- صور الصفحات تحت `output/pdf/images/`. ارفع PDF أو صوره؛ لا تضاعف الأدلة برفع النسختين دون حاجة.

المصادر: [خطة الشبكات وفرعي أمن المعلومات](https://www.aaup.edu/ar/bachelor-computer-networks-minor-information-security/curriculum)، [علم الحاسوب](https://www.aaup.edu/ar/bachelor-computer-science/curriculum)، [الذكاء الاصطناعي والروبوت](https://www.aaup.edu/ar/bachelor-artificial-intelligence-specialization-artificial-intelligence-and-robotics/curriculum). هذه إعادة تنظيم مستقلة للجداول، وليست وثائق أصدرتها الجامعة أو إثباتاً لسنة النفاذ أو الدفعة. لا يجلب السؤال الموقع؛ المصدر المستخدم هو النسخة المحلية المفهرسة، وروابطها مرتبطة بالشركة وبصمة الملف.

المساحة المشتركة بهذه المراجع تتحقق من تحديث المصدر دورياً، بحد أقصى فحص في الساعة. إزالة ملف مُدار أو إزالة الكل يوقف استيراد المراجع حتى تختاره مجدداً. يحتفظ `data/academic_sources/manifest.json` بحالة المصدر واللقطات؛ فشل التحديث يظهر كفشل تحقق مع إبقاء النسخة المحلية.

```powershell
uv run python scripts/evaluate_curricula.py
```

هذا تقييم مستقل لـ50 حالة استرجاع ضمن ملف الخطة المختار؛ يحتاج المراجع الناتجة من المزامنة. توجد أيضاً `scripts/evaluate_retrieval.py` و`data/eval/aaup_questions.jsonl` للملف الملخص وبعض حالات PDF الرسمي. PDF الأصلي مستثنى من Git، لذلك تُتخطى حالاته إن لم تضفه محلياً؛ لا تحسب التخطي نجاحاً.

## OCR وإعداد مزود الإجابات

```powershell
uv run rag-aaup setup-ocr
uv run rag-aaup doctor
```

ينزّل إعداد OCR نماذج العربية والإنجليزية من مستودع Tesseract الرسمي. تدعم الصور وPDF المصور؛ راجع الأرقام والرموز من الأصل. المراجع العربية المُصدرة من التطبيق تحتوي نصاً منطقياً مرفقاً ولا تحتاج OCR. لا تتضمن حزمة المقيّمين اختبار OCR لصور مجهولة.

للتوليد اضبط `LLM_PROVIDER=gemini` ومفتاحك ونموذجك، أو `LLM_PROVIDER=ollama` مع نموذج Ollama يعمل محلياً. مهلة المزود الافتراضية 40 ثانية، مع حد إجمالي للطلب وإتاحة المحاولة مجدداً بعد الخطأ. تُقرأ إعدادات التوليد من `.env` عند الطلب، ولا يصل المفتاح للواجهة. وجود المفتاح لا يثبت صلاحيته أو حصته. البحث في المصادر متاح دون LLM بعد تنزيل نموذج التضمين.

تُرسل مقتطفات الملفات وسياق المحادثة إلى مزود التوليد المختار؛ استخدم بيانات مصرحاً بها وراجع شروط المزود. تبقى الملفات والفهرس محلياً افتراضياً. لا يحتوي المستودع على مفاتيح أو بيانات الشركات.

## التخزين والوضع الفردي

التضمينات الدلالية في **Qdrant**، والبحث النصي FTS5 والبيانات الوصفية والمحادثات وبصمات الملفات في SQLite. يستعمل الاسترجاع multilingual-e5 ودمج RRF، ويفضل النسخة الأحدث مع إظهار المرجع الاحتياطي القديم عند الحاجة. احتفظ بأسماء إصدارات متسقة مثل `Student_Guide_2025.pdf` و`Student_Guide_2026.pdf`.

الوضع الافتراضي للمشغّل متعدد الشركات. للتوافق الفردي اضبط `MULTI_TENANT_ENABLED=false` واختر `RAW_DIR` و`DATABASE_PATH` وكلمة مرور `APP_PASSWORD`. عند إيقاف الخادم يمكن تشغيل `uv run rag-aaup index`؛ أثناء تشغيله استخدم تحديث الواجهة لتجنب قفل Qdrant المحلي. يمكن ضبط `QDRANT_URL` لخادم مستقل؛ يلزم اختباره وتأمينه في بيئة النشر، ولم يشمل التحقق المحلي خادماً خارجياً.

## الملفات المهمة وشروط المسابقة

```text
reviewer_pack/documents/  خمسة مستندات وهمية للرفع
reviewer_pack/cases.json  42 سؤالاً ومتوقعها - لا ترفعها إلى RAG
reviewer_pack/reports/    نتائج التشغيل الفعلي وحدود التقييم
src/rag_aaup/            التطبيق وAPI وQdrant والاسترجاع والواجهة
scripts/                تقييم الاسترجاع والإجابات وبناء مستندات الاختبار
tests/                  اختبارات الوحدة والتكامل ومنطق الواجهة
configs/                مصادر الخطط العامة المعتمدة
workspaces/             بيانات الشركات المحلية - مستثناة من Git
output/ وoutputs/        مخرجات التشغيل المحلية - مستثناة من Git
```

راجع [مواءمة دليل IEEE](./docs/competition_alignment.md). حزمة الجامعة الوهمية للاختبار الهندسي، ومراجع AAUP العامة إضافية؛ لا تستبدل حزمة الحقيقة التي توفرها اللجنة. يحتاج الفريق أدلة مشكلة وسوق حقيقية أو افتراضات موسومة، وعرضاً حتى 12 شريحة، وفهماً للكود وإفصاح الأدوات. لا تضمن الاختبارات علامة التحكيم.

استُخدم Codex للتنفيذ والمراجعة والاختبارات، وGemini لتوليد الإجابات من المقتطفات. مستندات المقيّمين قواعد وهمية مكتوبة صراحة للاختبار، ومراجع AAUP من جداول المصادر الرسمية. على الفريق مراجعة الحقائق والمصادر قبل العرض.
